# Age Proof Verifier Contracts

This directory contains the Solidity contracts and deployment scripts for verifying the Age Proof ZK circuit on-chain.

## Project Structure

- `verifier.sol`: The base verifier contract (generated by `bb`).
- `AgeProofVerifier.sol`: A wrapper contract for age proof verification.
- `scripts/deploy.js`: Deployment script for the contracts.
- `test/verifier.test.js`: Basic tests for the contracts.
- `hardhat.config.js`: Hardhat configuration for Arbitrum Sepolia.

## Deployment Flow

1. **Export the Verifier:**
   Run the following on your device to generate `verifier.sol`:
   ```bash
   # Generate VK with keccak hashing
   bb write_vk -b ../target/age_proof.json -o ../target/vk_keccak --oracle_hash keccak

   # Export Solidity verifier
   bb write_solidity_verifier -k ../target/vk_keccak/vk -o verifier.sol
   ```

2. **Setup Environment:**
   ```bash
   cp .env.example .env
   # Add your ARB_SEPOLIA_RPC_URL and PRIVATE_KEY to .env
   ```

3. **Install Dependencies:**
   ```bash
   npm install
   ```

4. **Deploy:**
   ```bash
   npx hardhat run scripts/deploy.js --network arbitrumSepolia
   ```
